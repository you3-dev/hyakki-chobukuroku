# 百鬼調伏録(ひゃっきちょうぶくろく)

妖怪を「倒す」のではなく「調伏(捕獲)」して配下にする、和風デッキ構築ローグライト。
iPhone向けPWA / 完全オフライン / 全操作タップのみ。

**現在: v1.0.0-rc.4 / M6-B完了**(五行を代表する憑合限定妖怪5種を追加し、全55種・54レシピへ拡張。GitHub PagesとiPhone実機の最終確認は未実施)

## 遊びの核

1. **調伏**: 敵のHPを30%以下に削って調伏札で捕獲。踏破済み夜行では「手加減」で単体攻撃の致死ダメージをHP1に抑えられる
2. **重ね**: 同種2体の憑合で★が上がり数値強化 — 既所持の妖怪との再遭遇にも意味がある
3. **憑合**: 異種レシピ54通りで新種を生む。全野生妖怪が最低1レシピの素材となり、四神(玄武/白虎/青龍/朱雀)と図鑑55種コンプが長期目標
4. **夜行**: 3つのダンジョンとクリア後の最終夜行をローグライトで踏破。負けても調伏した妖怪は持ち帰り
5. **呪具**: ボス・強戦闘・宝で手に入る装備品8種。妖怪1体に1つ

## 動かし方

- **PCで試す**: `index.html` をブラウザで開くだけ(ビルド不要・素のJS)
- **ローカルサーバー**: `python -m http.server 8000` → `http://localhost:8000`
- **iPhoneで試す**: 同一Wi-Fi内でPCのローカルサーバーにアクセス、またはHTTPSホスティング(GitHub Pages等)に置いてSafariで開き「ホーム画面に追加」

初回だけはオンラインで起動し、全資産のキャッシュ完了後にオフライン利用する。更新通知が出たら、先に必要に応じて引継ぎコードを控え、通知内の更新ボタンで最新版へ切り替える。

## セーブとバックアップ

- 操作の節目とラン途中はlocalStorageへ自動保存される
- 端末変更やブラウザデータ削除に備え、「記録」画面の「JSONを共有・保存」からファイルまたはクラウドへ保管する
- 復元は「JSONから復元」でファイルを選ぶ。従来の引継ぎコードも引き続き利用できる
- JSONと引継ぎコードの対象は手持ちなどの永続データで、進行中の夜行は含まれない

## 構成

```
index.html            エントリ(ビルドなし・classic script)
manifest.webmanifest  PWA名・アイコン・standalone表示設定
sw.js                 全実行アセットのオフラインキャッシュと版更新
css/style.css         デザイントークンと共通UIを含む全スタイル(縦横対応あり)
js/data.js            マスターデータ: 五行・妖怪55種・レシピ・呪具・ダンジョン・ボス
js/time.js            端末時刻の5区分・月齢/8月相・表示文言(純粋関数)
js/art.js             イラスト差し替え(assets/art/のSVGと絵文字を切替)
js/achievements.js    実績11件の定義・進捗計算・図鑑節目報酬
js/progression.js     次の目標・調伏師位階・選択報酬・最終クリア判定
assets/art/           妖怪イラスト(SVG)。仕様は assets/art/README.md
assets/icons/         iOS/PWA/favicon用アイコンと1024pxマスター
tests/                スモークテスト(node tests/*.js で実行)
js/state.js           永続データ(手持ち/デッキ/図鑑/呪具/戦績)・重ね・憑合・セーブ引継ぎ
js/run.js             ラン進行: ダンジョン・ノード生成・敵編成・宝/茶屋
js/battle.js          戦闘: 手札/霊力/属性/毒/弱体・調伏判定・手加減・呪具効果・式神代行(オート)
js/main.js            UI: 画面レンダリングとタップ操作(イベント委譲)
js/pwa.js             Service Worker登録・更新/オフライン状態表示
```

## 既知の制限

- SE/BGMなし
- セーブはlocalStorage。ラン途中のリロード復元と手持ちの引継ぎコードに対応
- 通常のSafariサイトはITPの7日制限対象。ホーム画面Webアプリのファーストパーティ領域は対象外だが、端末変更・容量不足・データ削除に備えてJSONバックアップを推奨
- iPhone実機のホーム画面起動・機内モード・更新適用はM5-Fのリリース検証で最終確認
