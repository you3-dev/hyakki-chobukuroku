# 百鬼調伏録(ひゃっきちょうぶくろく)

妖怪を「倒す」のではなく「調伏(捕獲)」して配下にする、和風デッキ構築ローグライト。
iPhone向けPWA / 完全オフライン / 全操作タップのみ。

**現在: P1本制作 第2弾まで実装済み**(第1弾: 重ね・図鑑・3ダンジョン・オート・セーブ引継ぎ / 第2弾: 呪具・妖怪50種)

## 遊びの核

1. **調伏**: 敵のHPを30%以下に削って調伏札で捕獲。倒せばEXP・捕まえれば戦力の排他報酬
2. **重ね**: 同種2体の憑合で★が上がり数値強化 — 既所持の妖怪との再遭遇にも意味がある
3. **憑合**: 異種レシピ32通りで新種を生む。四神(玄武/白虎/青龍/朱雀)と図鑑50種コンプが長期目標
4. **夜行**: 3つのダンジョンをローグライトで踏破。負けても調伏した妖怪は持ち帰り
5. **呪具**: ボス・強戦闘・宝で手に入る装備品8種。妖怪1体に1つ

## 動かし方

- **PCで試す**: `index.html` をブラウザで開くだけ(ビルド不要・素のJS)
- **ローカルサーバー**: `python -m http.server 8000` → `http://localhost:8000`
- **iPhoneで試す**: 同一Wi-Fi内でPCのローカルサーバーにアクセス、またはHTTPSホスティング(GitHub Pages等)に置いてSafariで開き「ホーム画面に追加」

## 構成

```
index.html            エントリ(ビルドなし・classic script)
manifest.webmanifest  PWAマニフェスト(最小限)
css/style.css         全スタイル(縦横対応は landscape メディアクエリ)
js/data.js            マスターデータ: 五行・妖怪50種・レシピ・呪具・ダンジョン・ボス
js/state.js           永続データ(手持ち/デッキ/図鑑/呪具/戦績)・重ね・憑合・セーブ引継ぎ
js/run.js             ラン進行: ダンジョン・ノード生成・敵編成・宝/茶屋
js/battle.js          戦闘: 手札/霊力/属性/毒/弱体・調伏判定・呪具効果・式神代行(オート)
js/main.js            UI: 画面レンダリングとタップ操作(イベント委譲)
```

## 既知の制限

- 絵は絵文字プレースホルダー、SE/BGMなし
- セーブはlocalStorage。**ラン途中でリロードするとランは消える**(手持ちは残る)
- iOS Safariは7日未使用でデータが消えることがある → 「記録」画面の引継ぎコードで対策
- Service Worker未実装(オフラインキャッシュ・アプリアイコンはP3で対応)
