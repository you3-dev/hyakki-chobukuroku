# イラストアセット仕様

絵文字プレースホルダーをイラストへ差し替えるためのフォルダ。**1体ずつ段階的に差し替え可能。**

## 組み込み手順(2ステップ)

1. `assets/art/<id>.svg` を置く(idは js/data.js の SPECIES / ITEMS / ボスのid)
2. `js/art.js` の `ART` 配列に `'<id>',` を1行追加

これだけで図鑑・手札・敵表示・憑合など全画面がイラスト表示に切り替わる。

## SVG仕様(必須)

- `viewBox="0 0 128 128"`、width/height属性は書かない
- 単一ファイル完結: 外部画像・外部フォント・script禁止(GitHub Pages/オフラインで安全に動かすため)
- 背景は透過。夜色の背景 `#151226` の上に置かれる前提で映える配色にする
- キャラ本体はキャンバスの約80%以内に収める(全キャラで大きさを揃えるため)
- ファイルサイズ目安: 10KB以下

## 画風ガイド(全キャラ統一)

- 和風・フラット塗り(2〜3階調)+太め輪郭線(stroke-width 4〜5、色は暗色 #5a2030 / #2a1f3d 系)
- ゆるくて少し不気味かわいい。`onibi.svg` が画風サンプル
- 妖怪の元ネタ(民話・伝承)の特徴を1つは入れる

## Codex等への依頼テンプレ

```
以下の仕様でSVGイラストを1ファイル作成してください。
- 対象: <名前>(<妖怪の説明。js/data.js の desc を貼る>)
- 出力先: assets/art/<id>.svg
- assets/art/README.md の仕様と画風ガイドに従うこと(onibi.svg が画風サンプル)
- 作成後、js/art.js の ART 配列に '<id>' を追加すること
```
