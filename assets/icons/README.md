# PWAアプリアイコン

M2.6で作成した『百鬼調伏録』のアプリアイコン。タイトル画面の鬼火を看板モチーフにし、濃紺の夜、金の月輪、朱の炎で構成する。文字は使わず、小サイズとOSマスクでの判読性を優先した。

## 採用デザイン

- モチーフ: 笑う鬼火 + 満月の輪
- 配色: `#151226`系の濃紺 / 金 / 朱 / 生成り / 濃紫の輪郭
- 背景: 不透明。画像自体に角丸を焼き込まない
- マスク: 円形と角丸矩形の両方で主要モチーフが切れないことを確認

候補は「鬼火+月輪」「鳥居+鬼火」「調伏札+火印」の3案を画像生成で比較し、タイトルとの一貫性、小サイズでの判読性、マスク耐性から鬼火+月輪を採用した。

## 最終生成プロンプト

組み込み画像生成を使用。要旨:

> 和風妖怪デッキ構築ゲームの正方形アプリアイコン。濃紺の不透明背景、中央に少し不気味でかわいい笑顔の鬼火、背後に細い金の満月輪。生成りの芯、朱の炎、濃紫の太い輪郭。フラットな2〜3階調、文字・漢字・透明・角丸・モックアップなし。主要要素は中央60%に収め、48pxと円形/角丸マスクで判別できる構図。

サイズ違いはマスターからLanczosで縮小し、RGB PNGとして保存する。
