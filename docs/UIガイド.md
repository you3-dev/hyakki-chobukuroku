# 百鬼調伏録 UIガイド

M5-Aで確定した、後続の画面仕上げに使う共通規則。実装の正は`css/style.css`の`:root`と共通クラスであり、この文書は判断基準をまとめる。

## 1. 方向性

- 夜の藍・紫を土台に、和紙の金を重要情報へ使う。時間帯テーマは空と光だけを変え、操作部品の意味色は変えない
- 情報は「画面名 → 現在値/目的 → 選択肢 → 補足」の順に置く
- 色だけで状態を伝えない。ON/OFF、選択中、装備中、🔒、危険な操作名などを文字または記号で併記する
- iPhoneを基準に、主要操作は44px以上。セーフエリアと縦スクロールを許容し、横スクロールは発生させない

## 2. デザイントークン

### 色

| 用途 | CSS変数 | 基準色 |
|---|---|---|
| 深い背景 | `--color-bg-deep` | `#151226` |
| 背景の明部 | `--color-bg-soft` | `#241d3d` |
| 通常面 | `--color-surface` | `#2b2447` |
| 浮いた面 | `--color-surface-raised` | `#362d59` |
| 本文/補足 | `--color-text` / `--color-text-muted` | 明るい藤色 / 灰藤色 |
| 重要・選択 | `--color-accent` | 金 `#e0b64e` |
| 通常の主要操作 | `--color-action` | 紫 `#7a68c9` |
| 危険/成功 | `--color-danger` / `--color-success` | 赤 / 緑 |
| キーボード焦点 | `--color-focus` | 明るい金 |

金は「重要・達成・選択」に限定し、画面内の通常ボタンすべてを金にしない。赤はデータ初期化、夜行放棄、進行破棄など結果を戻しにくい操作へ使う。

### 余白・形・影

- 余白は`--space-1`〜`--space-6`の4 / 8 / 12 / 16 / 24 / 32px
- 角丸は`--radius-sm` / `--radius-md` / `--radius-lg`
- 通常カードは`--shadow-card`、モーダルは`--shadow-float`
- 操作領域の下限は`--tap-min: 44px`

### 文字

- 日本語本文は`Hiragino Sans → Yu Gothic → Noto Sans JP → sans-serif`
- ゲームタイトルはA「切り絵・版画案」の`Yu Mincho → Hiragino Mincho ProN → serif`を採用し、本文・ボタンとの役割を分ける。採用仕様は [タイトルアート・ロゴ試作](./アート試作.md) を参照
- 端末設定による文字拡大を妨げず、本文基準は16px、補足でも原則`0.62rem`未満へ下げない
- タイトル・見出し・重要値は金、本文は白藤、説明は灰藤を使う

## 3. 共通部品

| 部品 | クラス/状態 | 使い方 |
|---|---|---|
| 通常ボタン | `.btn` | 戻る、詳細、補助操作 |
| 主要ボタン | `.btn.btn-primary` | 各まとまりで原則1つの「次へ進む」操作 |
| 危険ボタン | `.btn.btn-danger` | 初期化、夜行放棄、保存中ランの破棄 |
| 選択ボタン | `.btn.btn-active` | ONや現在選択中。文言・`aria-pressed`も併記 |
| カード | `.unit` / `.node-card` / `.enemy` | 同じ線、面、カード影を使う |
| 選択カード | `.selected` + `.unit-badge` | 金枠に加えて「選択中」「装備中」等を表示 |
| ロック | `.locked` + `aria-disabled` | 🔒、説明、破線、低彩度を組み合わせる |
| モーダル | `.unit-detail-overlay`または`.overlay` | 暗幕、浮いた面、`role="dialog"`、`aria-modal="true"` |
| 通知 | `.toast` / `.*-notice` | 操作結果は短文。重要な解放通知は閉じる操作を持つ |
| 画面見出し | `.screen-header` | 現在地、画面名、目的、要約値を同じ順序で示す |
| 節見出し | `.section-header` | 長い画面を目的単位に区切り、件数や短い補足を添える |
| 下部操作 | `.screen-actions` | 主要操作と戻る操作を画面間で揃え、縦画面では追従させる |
| 拠点の進捗 | `.home-summary` | 位階・図鑑・踏破・調伏を主CTAの後に1行チップで示す |
| 拠点の支度 | `.home-prep-menu` | 編成・憑合・呪具を3つの大きな操作として並べる |
| 拠点の記録 | `.home-record-menu` | 図鑑・実績・位階を3つの小さな操作として並べる |
| 拠点の補助 | `.home-utility-menu` | 遊び方・設定・引継ぎを44px以上の低強調操作として並べる |
| 節目演出 | `.celebration-overlay` / `.celebration-card` | 初見・調伏・憑合・報酬・解放だけを順番に強調する |

## 4. 操作状態

- `hover`: マウスがある端末だけ明度と境界を少し上げる。hover前提の情報は置かない
- `active`: 押した瞬間だけ軽く縮める。`prefers-reduced-motion`では変形しない
- `focus-visible`: 明るい金の2px枠と外側の淡いリングを全操作部品へ表示する
- `disabled`: 低彩度・低透明度にし、操作名は「無効」または解放条件とともに示す
- `selected`: 金枠だけでなく「選択中」「装備中」、ON/OFF、チェック記号のいずれかを併記する
- `danger`: 赤い面に加え、「初期化」「諦める」など結果が明確な動詞を使う

## 5. 演出とアクセシビリティ

- 画面遷移は主見出し、モーダルは最初の操作へフォーカスを移す。モーダル内のTab循環、Escapeで閉じる操作、起点への復帰を維持する。読み上げ用にプログラムフォーカスした見出し(`tabindex="-1"`)はTabで到達できないため、フォーカス輪郭を表示しない
- タップ可能なカードはEnter/Spaceでも実行できるようにし、役割、操作名、選択状態、無効状態を読み上げ可能にする
- 更新通知は通常操作を`role=status`、戦況の履歴を`role=log`、確認が必要な節目だけを`role=dialog`にする
- アニメーションは情報の理解を助ける短いものに限定し、`prefers-reduced-motion`と「演出を減らす」の双方で停止する
- SE/BGMは権利・容量・無音設定を同時に用意できる場合だけ追加する。M5-Dでは無音を維持する

## 6. PWA・セーフエリア

- 通常画面、タイトル、チュートリアル、結果、モーダル、固定通知は上下左右の`env(safe-area-inset-*)`を避け、横画面のDynamic Islandやホームインジケータへ操作を重ねない
- ブラウザとホーム画面起動は同じ情報構造を使い、`display-mode: standalone`はレイアウト変更ではなく高さ・余白の補助に限定する
- オフライン状態は`.pwa-status.pwa-offline`、更新待ちは`.pwa-status.pwa-update`で表示する。状態文と44px以上の更新操作を持たせ、色だけへ依存しない
- ピンチ拡大を禁止しない。PWAでも端末の文字サイズ、演出抑制、キーボード・読み上げ操作を維持する
