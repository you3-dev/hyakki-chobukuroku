## 作業の約束(全デバイス共通)

1. **テスト**: 変更後に必ず5つ実行し、ALL PASSを確認してからpush
   ```
   node tests/logic-smoke.js   # ゲームロジック+自動プレイシミュレーション
   node tests/ui-smoke.js      # 全画面のレンダリング+主要操作
   node tests/art-check.js     # イラストアセットの整合
   node tests/pwa-check.js     # PWA・オフライン資産の整合
   node tests/release-check.js # リリース版・文書の整合
   ```
2. **ドキュメント同期**: 数値・レシピ・妖怪を変えたら [仕様書](./仕様書.md) / [妖怪カタログ](./妖怪カタログ.md) を同じコミットで更新
3. **この計画の更新**: タスク完了で `[x]`、新タスクは適切なマイルストーンに追記
4. mainへ直接push運用(小さく頻繁に)。コンフリクトしそうな大きい変更だけブランチ+PR
5. 技術方針: ビルドなしの素のJS(classic script)を維持。npm依存を増やさない

スマホ運用の要。iPhoneはSafari/PWAをすぐ再読み込みするため、**ラン中にリロードすると夜行が消える**現状はモバイルで致命的。

- [x] ラン状態(R)と戦闘状態(B)をlocalStorageへ随時保存(ノード遷移時・ターン終了時)

- [x] 戦闘は「そのターン開始時点」への復元でよい(手札・山札・敵HP・霊力を保存)
- [x] 引継ぎコード(exportSave)にはラン状態を**含めない**(手持ちだけ持ち運ぶ現仕様を維持)

## M4.6: 手加減・再調伏支援

育成済みの妖怪で序盤ダンジョンへ戻ると、調伏可能なHP30%以下へ到達する前に敵を倒してしまう問題を解消する。敵HPを味方の強さに合わせて増やす方式は成長実感を損なうため採用せず、**一度攻略した場所での収集を快適にする任意操作**として追加する。

### 解放条件と基本操作

- [x] ダンジョンごとに初回踏破後、「🪶 手加減」を解放する。初回攻略中と未踏破ダンジョンでは使用できず、既存の式神代行と同じ解放条件に揃える
- [x] 戦闘画面の調伏操作付近に44px以上の手加減切替ボタンを表示し、ON/OFFを色だけでなく文言・アイコンでも示す
- [x] 手加減ON中、非ボスへの**単体カードの直接ダメージ**が致死量ならHP1で止める。非致死ダメージは通常どおり与え、ON状態はプレイヤーが解除するか戦闘終了まで維持する
- [x] HP1で止めた時は「手加減して踏みとどまらせた」ログと短い視覚表示を出し、そのターン中に通常どおり調伏できることを分かりやすくする

### 適用外とバランス境界

- [x] ボス、全体攻撃、毒の継続ダメージ、敵ターンの処理には手加減を適用しない。毒付き単体攻撃の直接ダメージだけはHP1で止めるが、調伏せずターンを終えれば毒で倒れる可能性を残す
- [x] 手加減自体は霊力・調伏札を消費しない。カード使用時の霊力と調伏時の「霊力1+調伏札1」は従来どおり必要とし、捕獲資源を無償化しない
- [x] 式神代行は手加減を使わず、調伏もしない。敵の自動スケーリング、常時HP1停止、満タンHPからの先制調伏は今回の範囲外とする
- [x] 戦闘開始時はOFF。ラン途中セーブでは戦闘中のON/OFFを復元し、別の戦闘や次の夜行へは持ち越さない
