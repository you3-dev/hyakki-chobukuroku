## 作業の約束(全デバイス共通)

1. **テスト**: 変更後に必ず3つ実行し、ALL PASSを確認してからpush
   ```
   node tests/logic-smoke.js   # ゲームロジック+自動プレイシミュレーション
   node tests/ui-smoke.js      # 全画面のレンダリング+主要操作
   node tests/art-check.js     # イラストアセットの整合
   ```
2. **ドキュメント同期**: 数値・レシピ・妖怪を変えたら [仕様書](./仕様書.md) / [妖怪カタログ](./妖怪カタログ.md) を同じコミットで更新
3. **この計画の更新**: タスク完了で `[x]`、新タスクは適切なマイルストーンに追記
4. mainへ直接push運用(小さく頻繁に)。コンフリクトしそうな大きい変更だけブランチ+PR
5. 技術方針: ビルドなしの素のJS(classic script)を維持。npm依存を増やさない

## M1: ラン途中セーブ(最優先)

スマホ運用の要。iPhoneはSafari/PWAをすぐ再読み込みするため、**ラン中にリロードすると夜行が消える**現状はモバイルで致命的。

- [x] ラン状態(R)と戦闘状態(B)をlocalStorageへ随時保存(ノード遷移時・ターン終了時)
- [x] 起動時に進行中ランがあれば「夜行を再開する/諦める」を選べる
- [x] 戦闘は「そのターン開始時点」への復元でよい(手札・山札・敵HP・霊力を保存)
- [x] 引継ぎコード(exportSave)にはラン状態を**含めない**(手持ちだけ持ち運ぶ現仕様を維持)
- [x] テスト追加: 保存→復元でランが一致すること
- 完了条件: バトル中にリロードしても同じ戦闘のターン頭から続きが遊べる → ✅ 達成(調伏成功・決着時は即時上書き保存で二重取得を防止。仕様書8章参照)
