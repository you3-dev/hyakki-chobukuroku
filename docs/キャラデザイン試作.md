# キャラクターデザイン試作

- 試作日: 2026-07-22
- 状態: **全55体・通常ボス3体・再臨ボス3体をRC7へ採用**
- 対象: 鬼火、唐傘お化け、化け狸、鎌鼬、木霊、提灯お化け、猫又、川獺、河童、山童、土蜘蛛、一つ目小僧、天邪鬼、送り犬、泥田坊、管狐、雨降小僧、雪女、からす天狗、大蝦蟇、鵺、座敷童子、骸骨武者、火車、不知火、百目、山姥、大入道、以津真天、濡女、覚、海坊主、朧車、大天狗、九尾の狐、鎧武者、龍神、大百足、八咫烏、妖刀村正、九十九神、玉藻前、麒麟、白澤、祟り神、玄武、白虎、青龍、朱雀、ぬらりひょん、風狸、輪入道、塗壁、鉄鼠、磯撫

## 狙い

特定作家・作品の画風を直接複製せず、80〜90年代の冒険少年漫画に見られる要素を分解して、現在の妖怪を「戦える仲間キャラクター」へ再設計した。

- 太く強弱のある輪郭線
- 一目で性格が分かる眉、目、口
- 丸みのある明快なシルエット
- 少ない色数と2段階程度の陰影
- 道具、服装、ポーズによる役割付け
- 128×128へ縮小しても種族を判別できる形

## 画風ルール v1

唐傘お化け、化け狸、鬼火v2を初期基準として、以後の試作では次を共通化する。

### 必須要素

- **妖怪性を先に置く:** 人間の格闘家へ寄せず、動物、器物、自然現象など元の怪異が一目で分かる骨格にする。
- **太い墨線と明快な輪郭:** 外周は太く、内側は一段細くする。128×128でも顔と種族固有部位が残る形を優先する。
- **丸みと非対称:** 親しみやすい丸みを基本に、補修跡、炎の揺らぎ、尾、葉、風などで少し崩して怪異らしさを出す。
- **表情は一つに絞る:** いたずら、臆病、無愛想など、性格を眉・目・口の組み合わせだけでも読めるようにする。
- **役割を小道具と動きで示す:** 攻は前進や刃の軌跡、守は受け止める面、妙は袋・葉・響きなど、能力と結び付く要素を一つ持たせる。
- **少ない色数と2段階陰影:** 本体色2〜3色、差し色1色、濃紺の線を基本とし、細かなグラデーションに依存しない。
- **版画調の質感:** 和紙の粒子、かすれた円形の刷り跡、限定的な朱・金・紫を使い、タイトルの切り絵・版画案とつなぐ。

### 避けること

- 筋肉質な人体、握り拳、格闘ポーズを安易に足して熱血主人公化すること
- 武器や衣装だけで元の妖怪が判別できなくなること
- 写実的な毛並みや複雑な背景で、小さいカード表示の輪郭を埋めること
- 既存作品や特定作家の固有キャラクター、衣装、顔つきを再現すること

### 画面構成

- 正方形の単体キャラクター画を基本とし、全身と固有シルエットを中央80%以内へ収める。
- 背景は生成確認用の和紙色と円形の刷り跡に限定する。本番化時にはキャラクター切り抜きと背景を分離する。
- 文字、カード枠、数値、ロゴは画像へ焼き込まない。

## キャラクターごとの判断

| 妖怪 | 強くなった点 | 採用時の注意 |
|---|---|---|
| 鬼火 | v2では拳・脚・格闘姿勢を外し、浮遊、非対称の炎、小さな牙、紫の鬼火縁で妖怪性を戻した | v1は熱血主人公に見えるため不採用候補。v2を比較基準にする |
| 唐傘お化け | 傘骨、補修跡、下駄で付喪神らしい情報量が増えた | 傘の横幅が大きいため、カード内の安全余白を個別調整する |
| 化け狸 | 旅装、袋、葉、尾で収集・補助役の物語が伝わる | 衣装の意味を能力や設定へ反映しないと装飾だけに見える可能性がある |
| 鎌鼬 | 獣の骨格、鎌状の前脚、尾と旋風の円運動で高速攻撃役を表現した | 爪と風の情報量が多いため、128×128では顔・前脚・尾を優先して簡略化する |
| 木霊 | 古木の空洞、年輪、若葉、響きの輪と種の光で、怪異と回復役を両立した | 拡大画では成立するが、縮小時には指や細い根を整理し、空洞の顔と若葉を主記号にする |
| 提灯お化け | 破れた紙、補修跡、竹骨、縄の四肢、内側の灯りで、唐傘と同系統の付喪神として防御役を表現した | 破れ目が細かいため、縮小時は一つ目と朱い提灯形を最優先する |
| 猫又 | 二本の尾、爪の軌跡、札を見る仕草で「攻撃しながら次の手を読む」役割を表現した | 札の細部は縮小すると潰れるため、二本尾と金の目を種族識別の主記号にする |
| 川獺 | 長い胴と尾、水撃、葉の仮面で川の攻撃役と変化の悪戯者を両立した | 水しぶきが輪郭を囲みすぎないよう、カード実装時は本体との明度差を確保する |
| 河童 | 皿、甲羅、水掻き、胡瓜飾りを残し、丸い胴と低い相撲の構えで非人型の怪異に寄せた | 初稿は筋肉質だったため不採用。人間の力士に戻らないよう、丸胴・短脚を維持する |
| 山童 | 山猿の骨格、蓑、苔、丸太で山暮らしと怪力攻撃を表現した | 丸太の占有面積が大きいため、縮小時も顔と前腕が隠れない配置を維持する |
| 土蜘蛛 | 八本脚、土器状の外骨格、補修縄、張った糸で攻防一体の古豪を表現した | 脚と甲羅の線が多いため、128×128では脚を四対の大きな塊として整理する |
| 一つ目小僧 | 巨大な一眼、長すぎる袖、小さな下駄で、視線攻撃と小怪異らしい愛嬌を両立した | 縮小時は眼の金色と暗い袖を主記号にし、熱波の輪は本数を減らす |
| 天邪鬼 | 左右非対称の角、裏向きの衝立、背後から抜く札で、逆張りによる防御と追加選択を表現した | 小道具が多いため、128×128では顔・角・衝立の三要素を優先する |
| 送り犬 | 四足の山犬、振り返る視線、足跡、牙の紫煙で、追尾と残る噛み傷を表現した | 黒い毛並みが潰れないよう、顔・胸・脚に明るい差し毛を残す |
| 泥田坊 | 田泥、稲根、畦杭、単眼、丸い三本指で、粘り強さと土地への執念を仲間向けに表現した | 初稿は牙と巨大な手がホラー寄りだったため不採用。疲れた単眼と小さな口を維持する |
| 管狐 | 竹筒から細長い狐が飛び出すS字構図で、小ささ、速さ、噛みつきの余韻を表現した | 管と狐の明度差を保ち、縮小時にも竹筒から出ている関係が読めるようにする |
| 雨降小僧 | 水を受ける大編笠、水の防護幕、足元の芽で、防御と回復を同時に表現した | 唐傘と混同しないよう、一つ目や舌を足さず、笠の下の小さな雨霊を必ず見せる |
| 雪女 | 大きな白い仮面顔、丸い袖、足のない吹雪の渦で、美少女化を避けた冷気の怪異にした | 初稿は高頭身で高位キャラに見えたため不採用。三頭身と整理した雪片数を維持する |
| からす天狗 | 鳥の骨格、羽根付き木刀、翼と風の円運動で、黒翼の剣士と全体攻撃を表現した | 黒い翼が潰れないよう、顔・木刀・風の明度差を保つ |
| 大蝦蟇 | 岩状の疣、大きな腹、低い四足姿勢、小さな毒煙で、防御と継続傷を表現した | 河童と混同しないよう、皿・甲羅・人型の構えを足さない |
| 鵺 | 猿顔、虎脚、蛇尾を一つの四足獣へ自然につなぎ、黒雲と稲妻で弱体攻撃を表現した | 128×128でも蛇尾の頭が背景へ溶けないよう、輪郭と目の色を残す |
| 座敷童子 | 郷土人形風の顔、大きな袖、札、独楽で、福・札獲得・小防御をまとめた | 現実の子どもや美少女へ寄せず、黒い丸目と三頭身を維持する |
| 骸骨武者 | 大きな頭蓋、簡略化した骨、古い甲冑、一閃で、怖さよりも残った剣技を表現した | 甲冑の情報量が多いため、縮小時は頭蓋・刀・朱紐を主記号にする |
| 火車 | 一本尾の黒猫、燃える古車輪、爪の火線で、猫又と差別化した継続火傷役にした | 猫又化を避けるため、二本尾や札を足さず、火輪を必ず残す |
| 不知火 | 一眼の中央火と四つの従火を海上で連ね、単体の鬼火と異なる集団怪火として全体攻撃を表現した | 五つの炎が縮小で一塊にならないよう、各炎の濃紺の間隔を保つ |
| 百目 | 土器の外套と満月を大きな塊にし、大小の眼で観察・防御役を表現した | 小さな眼を増やしすぎず、128×128では中央の大眼と満月を優先する |
| 山姥 | 木の杵と光る薬草を対にし、攻撃と回復を担う山の古怪としてまとめた | 現実的な老婆へ寄せず、低い姿勢・根のような髪・蓑の輪郭を維持する |
| 大入道 | 石と土のような法衣の巨体、数珠、踏み割る地面で重量級の攻防を表現した | 縮小時にも頭と踏み出す足が切れないよう余白を確保し、普通の僧に戻さない |
| 以津真天 | 刃状に開いた翼、盾のように畳んだ翼、鳴き声の輪で全体攻撃と防御を表現した | からす天狗との差別化のため、武器や頭巾を持たせず鳥の骨格を主役にする |
| 濡女 | 太い蛇身、白い仮面顔、濡れた紺髪、毒煙で水辺の毒怪を表現した | 美しい人魚や人間の胴体へ寄せず、蛇のとぐろを最も大きな主記号にする |
| 覚 | 山猿の骨格、大きな耳、鏡、浮く札、満月で読心と手札操作を表現した | 脳を露出させず、128×128では耳・目・鏡の三要素を優先する |
| 海坊主 | 衣服も脚もない巨大な海影を波の腕と渦へ溶かし、全体を襲う潮撃を表現した | 大入道との差別化のため、法衣・数珠・足を加えず、下半身を必ず波にする |
| 朧車 | 牛車の車体と破れた御簾から一つの顔を生やし、紫の怨念煙で攻防を表現した | 火車・輪入道との差別化のため、炎の車輪ではなく車体全体を主役にする |
| 大天狗 | 長い赤鼻、巨大な黒翼、羽団扇、山嵐の円運動で高位の全体攻撃役を表現した | からす天狗との差別化のため、刀を持たせず、面・団扇・翼の格を優先する |
| 九尾の狐 | 狐の獣体と九本の炎形の尾を紋章状に広げ、攻撃と吸収回復を表現した | 人型や美女へ寄せず、縮小時にも九つの尾先が読める間隔を保つ |
| 鎧武者 | 中身のない大鎧、暗い面頬の金眼、組んだ巨大籠手で鉄壁の守りを表現した | 骸骨武者との差別化のため、頭蓋や骨、斬撃を見せず鎧の空洞を維持する |
| 龍神 | 太い龍体と逆巻く水流を一つの円へまとめ、全体を呑む濁流を表現した | 人型の龍王へ寄せず、128×128では顔・角・胴の輪・水流を主記号にする |
| 大百足 | 石鎧状の節を山へ巻き付け、巨大な顎と崩れる岩で単体大打撃を表現した | 脚を細線の集合にせず、節ごとの大きな脚の組として整理する |

## 推奨する次の確認

1. 3体を既存のカード拡大モーダルへ仮表示し、現行SVGとの見え方を比較する。
