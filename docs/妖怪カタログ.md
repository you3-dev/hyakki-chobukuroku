# 妖怪カタログ(50種+ボス3体)

- ステータス: v0.3(実装=js/data.jsと同期。**コードを変えたらここも直す**)
- 数値はLv1・★0・呪具なし時点。成長則は[仕様書](./仕様書.md)4章参照
- tier1=雑魚 / tier2=上位種(調伏成功率-10%)/ 憑合=合体でのみ入手
- **同種×同種はレシピ不要の「重ね」(★+1、上限★3)**

## 時間帯・月相による出現条件(M3-C)

条件は出撃開始時に固定される。条件一致時は通常候補より抽選重みが高くなる。時間帯条件の不一致時は候補から外れるが、満月レア2種は満月外でも低確率で出現する。無条件の妖怪は全時間帯で出現する。
