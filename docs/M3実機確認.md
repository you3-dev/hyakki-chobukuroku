# M3実機確認チェックシート

M3-Dの残作業。GitHub PagesへM3をpushした後、iPhoneのSafariまたはホーム画面版で確認する。

## 1. 時間表示・途中再開・日付またぎ

- [ ] タイトルと拠点に同じ時間帯・月相が表示される
- [ ] 現在時刻に応じて朝/昼/夕/夜/丑三つの背景色と文言が変わる
- [ ] 夜行を開始し、開始時の時間帯・月相を控える
- [ ] 戦闘途中でアプリを閉じ、再起動後に「夜行を再開する」から同じターン頭へ戻れる
- [ ] 夜行中に端末時刻を別の時間帯へ変えても、再開したランの出現条件は開始時のまま固定される
- [ ] 拠点へ帰還後に再描画すると、新しい端末時刻の背景・表示へ切り替わる
- [ ] 日付をまたいでも進行中ランを再開でき、ランの月相は開始時のまま固定される
- [ ] 端末時刻を変えても警告・報酬減少・操作制限が出ない
- [ ] 確認後、iPhoneの「日付と時刻」を自動設定へ戻す
